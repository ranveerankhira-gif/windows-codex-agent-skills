# 安全与权限

- **读取**：通过 Codex 原生任务工具读取当前项目中未归档任务的必要对话内容，不读取数据库或底层会话文件。
- **写入**：只修改用户已确认预览中的任务标题。
- **网络与凭据**：不需要外部网络或账号凭据。
- **费用**：不调用付费服务。
- **隐私**：标题是侧栏可见元数据。不得把密码、令牌、Cookie、联系方式、完整本机路径或其他非必要敏感内容写入标题。
- **确认边界**：生成完整预览是只读；只有明确引用当前预览编号的全部批准，或明确列出任务 ID 的部分批准，才能执行。单独的“继续”“可以”“好的”不算批准。不得顺带归档、移动、删除、置顶或发送消息。
- **并发与回滚**：写入前重新核对任务集合、ID、旧标题、项目和归档状态。逐项改名并逐项核验；失败后停止后续操作，并仅在当前标题仍是本轮新标题时逆序恢复旧标题。
- **工具边界**：只使用 Codex 原生任务列表、读取和标题修改能力；不读取或编辑 SQLite、rollout、会话目录、AppData 或配置文件，也不用浏览器、桌面自动化或私有 API 作为后备方案。
