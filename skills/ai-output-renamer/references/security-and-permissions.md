# 安全与权限

- **读取**：只读取用户通过 `-LibraryRoot` 或 `AI_OUTPUT_LIBRARY_ROOT` 指定、且已包含 `_系统与索引/文件索引.json` 的副本库、索引及为命名所需的副本内容。
- **写入**：清单命令只在副本库外新建清单且拒绝覆盖；应用和撤销只在该副本库内更新展示名、分类、索引和事务记录。`SourcePaths` 指向的源文件始终只读。
- **网络与凭据**：脚本不需要网络、账号、Cookie 或 Token。
- **费用**：不调用付费服务。
- **路径边界**：拒绝卷根目录、符号链接、Windows 联接点、其他重解析点、Windows 保留名称、路径组件注入和把普通副本移入系统索引区。递归删除只处理受控暂存根目录的直接子目录，且要求内容匹配的所有权标记。
- **确认边界**：生成清单是只读；应用计划和撤销会改动副本库，必须由用户显式调用。路径越界、哈希变化、索引损坏或回滚不完整时停止；回滚不完整会保留事务标记。
