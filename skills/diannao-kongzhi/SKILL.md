# 电脑控制

执行前读取 [安全与权限](references/security-and-permissions.md)。

本 Skill 只通过 `$diannao-kongzhi` 显式调用。目标是用最窄权限、最少截图和最少输出完成 Windows 桌面操作，不提升系统权限。它依赖用户另行安装并审查的 `Safe-WinApp.ps1`；本 Skill 不下载或安装该包装器。

## 启用与授权边界

- 用户显式调用 `$diannao-kongzhi` 并明确要求排查、读取、控制或修复某个桌面软件时，该请求授权在所述任务范围内启用本 Skill，无需重复询问是否启用。
- 首次调用包装器、列举窗口、读取控件或截图前，用简短进度说明告知准备控制的软件、动作和影响；普通读取和可逆操作可以继续，高影响最终动作仍按后文逐次确认。
- 授权仅覆盖用户所指的软件、数据和目标，不得借此读取无关窗口、其他软件或扩大任务范围。若用户只是在讨论一般方法、没有要求实际查看或操作本机，不得接触桌面。
- 普通读取、导航、启动、聚焦、填写以及可验证、可逆的操作不再逐步确认；仍须遵守后文对高影响最终动作的逐次确认要求。

## 先选更直接的接口

1. 浏览器页面优先使用浏览器 DOM 自动化。
2. 文档、表格、PDF 或代码优先直接操作文件。
3. 应用已有 CLI、API 或专用工具时优先使用它们。
4. 只有必须操作 Windows 桌面 UI 时才使用本 Skill。

## 固定安全边界

- 只调用用户审核并通过 `SAFE_WINAPP_WRAPPER` 配置的 `Safe-WinApp.ps1`，且其 SHA-256 必须与 `SAFE_WINAPP_WRAPPER_SHA256` 完全一致；不得直接调用底层 `winapp.exe`。任一配置缺失或哈希不符时停止，不猜测路径，也不自动下载替代工具。
- 不以管理员身份运行，不请求 UIAccess，不处理 UAC 或安全桌面。
- 不绕过包装器对按键注入、坐标点击、录制、PostMessage、全屏捕获及覆盖写入的限制。窗口根节点无法被标准 `focus` 选中但只需置前时，可使用精确身份校验的 `activate-window`；它不发送点击或按键。公开版不包含任何软件专用坐标例外。
- 若受限命令无法完成任务，说明具体缺少的能力并停止；不得改用更宽权限工具偷偷完成。
- 不读取或填写密码、验证码、密码管理器、银行/支付、账户安全或安全软件界面。

## 操作流程

1. 首次操作前确认包装器存在，并运行 `version`；若文件缺失或版本异常则停止。
2. 用 `list-windows` 找到目标窗口。存在多个候选时，用窗口标题和进程信息消歧，不猜测。
3. 锁定窗口句柄后，后续命令都带 `-w <handle>`。优先 `search`，需要时才用精简的 `inspect`。仅需置前而窗口根节点无法被标准 `focus` 选中时，使用 `activate-window` 并同时提供精确标题和进程名。
4. 写入字段用 `set-value`，调用控件用 `invoke`；每次改变后用 `get-value`、`get-property` 或 `wait-for` 验证结果。
5. 若自绘模态弹窗完全不暴露子控件，且用户已经明确要求关闭该弹窗，才可按 [references/commands.md](references/commands.md) 的严格前置条件使用 `dismiss-modal`；它不是通用关闭窗口命令，也不能作为坐标点击的替代品。
6. 结构信息仍不足时才做窗口级 `screenshot -w <handle>`；禁止全屏截图。
7. 选择器失效、歧义或窗口状态变化时重新搜索，不沿用旧猜测。

执行实际命令前读取 [references/commands.md](references/commands.md)。

## 什么时候必须先问用户

普通、可逆、且用户已明确要求的填写、导航和读取无需逐步确认。以下动作必须在最后一步前清楚说明“将发生什么、影响什么、是否可撤销”，并等待用户明确确认：

- 删除、覆盖、清空、丢弃未保存内容或关闭含未保存内容的窗口；
- 发送、发布、提交、购买、付款、签署或对外共享；
- 修改账号、权限、隐私、安全、订阅或系统设置；
- 任何涉及法律、金融或真实身份的最终提交。

提问必须具体，例如：“下一步会把这封邮件发送给张三，发送后对方立即收到，普通撤销不能保证追回。要执行发送吗？”不要只问“是否确认”。

## 多实例与额度控制

- 每个逻辑工作流生成独立 `WINAPP_UI_WORKFLOW_ID`，避免多个 Codex 相互占用桌面控制。
- 先搜索控件，再局部检查；不重复输出完整控件树。
- 只截目标窗口，只在文本结构不足时截图。
- 合并连续的只读检查，但每个有状态改变的动作都要单独验证。

## 结束报告

简短报告已完成的动作、验证到的结果，以及未完成或被安全边界阻止的部分。不要声称成功，除非已读取到可验证的界面状态。
