# 安全与权限

- **读取**：可读取用户指定窗口的标题、控件树、必要状态和窗口级截图；不扫描无关窗口或文件，不做全屏捕获，也不持久保存截图，除非用户明确要求。
- **写入**：仅通过用户配置、审查并锁定 SHA-256 的受限 UI Automation 包装器操作目标控件。不得直接调用底层自动化程序、按键注入或坐标点击接口。
- **网络与凭据**：不读取、记录或代填密码、验证码、Token、Cookie；不自动联网。
- **费用**：不调用付费服务。
- **确认边界**：查看状态和用户已要求的可逆操作可以执行；发送、提交、删除、购买、发布、账号或系统设置更改必须在最后动作前得到明确确认。包装器缺失、哈希变化或能力不足时停止，不下载替代品或换用更宽权限工具。
