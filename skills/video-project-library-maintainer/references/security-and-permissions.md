# 安全与权限

- **读取**：只读取用户用绝对路径明确指定的视频项目、交付清单和媒体元数据；拒绝符号链接、目录联接和其他 Windows 重解析点。
- **写入**：在 `--library-root` 或 `VIDEO_PROJECT_LIBRARY_ROOT` 指定的资料库创建受管项目、索引、精选副本、历史快照和可选桌面快捷方式；源项目不移动、不覆盖。
- **网络与凭据**：不联网，不读取账号凭据。
- **费用**：不调用付费服务，但复制大型审阅文件会占用磁盘。
- **确认边界**：无 `--apply` 时只预演；注册、复制、刷新索引、创建工程或快捷方式必须在人工核对预演后显式加 `--apply`。自动发布、上传、下载、移动或改写源工程不属于本 Skill 能力。

## 受控替换与回滚

- 既有项目必须带 `.video-project-library-managed-project.json`，且项目根目录、目录名和标记一致；同名普通目录不会被接管。
- 写入时创建独占锁。审核视图、源位置记录和机器清单先写入带所有权标记的项目内暂存目录，再成组提升；失败时恢复旧目录。
- 递归清理只允许处理当前项目内或项目父目录内、名称符合本次暂存规则且含匹配所有权标记的目录。不会递归清理任意用户路径。
- `final-delivery` 的 JSON、依赖深度和依赖数量有上限；每个绑定必须精确匹配路径、SHA-256 和大小。疑似依赖缺失即停止，不静默忽略。
- 快捷方式只接受绝对 `.lnk` 路径；同名不同目标时拒绝覆盖，创建失败时清理本次临时快捷方式并回滚新建的空资料库目录。
