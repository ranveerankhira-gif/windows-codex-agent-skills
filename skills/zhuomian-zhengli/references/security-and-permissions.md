# 安全与权限

- **平台与依赖**：仅适用于 Windows 10/11；脚本要求 PowerShell 7（`pwsh`），不要求管理员权限。若只读 Shell 盘点遭遇 `E_ACCESSDENIED`，应报告并让用户决定是否授权提升权限，不能自动提权。
- **读取**：通过 Windows Shell/COM 读取当前桌面项目的完整解析路径、文件夹/虚拟项目类型、图标坐标、图标间距、工作区尺寸、自动排列状态和 Explorer 进程标识。完整路径可能泄露用户名、文件名、应用和工作内容。
- **写入与外部状态**：只在确认后用 `IFolderView.SelectAndPositionItems` 一次性应用已验证的图标坐标；不改文件内容、文件名、目录归属、壁纸、主题、显示设置或注册表。清理请求另按 `cleanup-policy.md` 生成候选清单，默认只允许经确认后把明确项目移入回收站。
- **本地文件**：清单、计划、回滚快照、结果 JSON 和截图都可能含私人桌面信息，必须保存到用户批准的私有目录，不得放进 Skill 目录、公开仓库或发行包。输出和快照只写入显式路径，父目录必须已存在，并拒绝覆盖同名文件。
- **网络、凭据与费用**：不联网、不上传文件、不读取浏览器、账号、密钥或其他凭据，不调用付费服务。
- **确认边界**：盘点、计划和预检只读。`APPLY-ICON-LAYOUT` 只对应用户刚确认的预算内计划；`APPLY-LARGE-REFLOW` 只对应用户单独确认的超预算计划；`ROLLBACK-ICON-LAYOUT` 只在用户确认恢复指定快照后使用。令牌是脚本防误触门槛，不代替对具体计划或快照的当前确认。
- **失败与恢复**：应用前写入不覆盖的回滚快照；坐标不一致或 Explorer 重启时自动尝试恢复。若恢复失败，停止后续操作并报告快照路径、恢复错误和未恢复项目，不做逐个拖动式修补。
- **公开边界**：真实文件名、路径、坐标、桌面截图、布局快照、显示器标识和恢复状态不得提交。`desktop-profile.example.md` 与 `plan-schema.md` 只提供虚构数据。
