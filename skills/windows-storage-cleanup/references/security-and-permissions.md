# 安全与权限

- **平台与依赖**：仅适用于 Windows 10/11。内置脚本兼容 Windows PowerShell 5.1+ 与 PowerShell 7+；WizTree 是可选的用户自备工具，缺失或导出失败时使用有边界、跳过重解析点的原生只读扫描。
- **读取**：可读取用户指定磁盘的容量、路径、文件大小、时间、属性、哈希、目录成员、安装归属、依赖声明、活动进程和目标盘回收站元数据。文件名、目录名、进程和清单可能暴露私人项目；不读取与判断无关的文件正文。
- **写入与外部状态**：仅处理用户在当前任务中确认清单里的精确绝对路径和处理方式。可能的动作包括官方清理、注册卸载、移入回收站、精确永久删除、应用维护接口或系统设置修改；这些都必须在动作前获得覆盖该范围的明确授权。
- **删除边界**：禁止用通配符、相对路径、父目录推断、`Clear-RecycleBin` 或整盘/整根递归删除代替精确清单。每个目标需复核类型、大小、时间、重解析点、占用、适用哈希及保留副本；改变、忙碌、越界或归属不明的项目跳过，不以新目标补足释放量。
- **过程文件**：WizTree CSV、目录清单、候选清单、回收站快照和核验报告保存在用户批准的私有任务目录，不进入 Skill 目录、公开仓库或发行包。临时文件只在受控临时根内创建；递归清理必须同时验证绝对路径、所有权标记和非重解析点。
- **网络与凭据**：普通本地审计不联网。仅当用户明确要求核验远端备份或云端副本时，才使用受信任的只读接口；不得收集、输出或复制密码、Cookie、Token 等凭据，也不得把本地文件上传到新的目的地。
- **费用**：不默认调用付费服务；若所选远端接口可能计费或消耗配额，先说明并确认。
- **确认边界**：扫描、分类和清单只读；prepare/候选生成不是 purge/删除授权。准确授权只能复用于当前任务中未变化的同一批目标和同一处理方式。清空整个回收站、永久删除、卸载、修改页面文件或其他系统设置必须由授权明确覆盖；路径、内容、归属、恢复条件或处理方式变化即停止该项。
- **失败与验证**：一项失败不扩大权限，也不阻止其他独立且仍符合授权的项目。完成后逐项核对路径或回收站条目、保护项、实际可用空间和恢复状态；回收暂存占用不能冒充已释放空间。
